# Pass-Through Two-Way Portal
A system portal type seen at a station: "Type: Pass-Through two-way portal. Gated by conveyance type and to key holders." The portal enforces gating (requires compatible conveyance or an equipped/held key), displays environment compatibility, and can route train tracks that run straight through the gateway into a multi-track root system.
