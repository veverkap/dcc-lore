# pass-through_two-way_portal

• Type: Pass-Through two-way [[portal]]
• Gated by conveyance type and to key holders
• Enforces gating (requires compatible conveyance or an equipped/held key)
• Displays environment compatibility
• Can route [[train]] tracks that run straight through the gateway into a multi-track root system
• Located at the [[Switching Station]]
• Far side is a branching root-liked track system and a zombie-filled [[trainyard]]
• [[Gate]] rules require being on a gated conveyance or holding/equipping a compatible key to pass
• Tracks connect to a sprawling root-system of diverging tracks
