# mock_battle_arena

• A situationally-generated [[arena]] room used for practice combat, displaying system warnings and spawning non-lethal generated mobs.
• Hosts system messages such as [[Combat Started]] and [[Combat Complete]].
• Allows environment customization and [[deck]] composition warnings.
• Spawns interactive NPCs and environmental layouts.
• Enforces [[arena]] rules such as locked decks and consumable restrictions.
• Has safeties that block certain debuffs and can run specialized modes like [[Secret Challenge Mode]].
• Hosts environment options such as [[Arena of the Eulogist]] and [[Abandoned arena]].
• Enforces [[deck]] and summon rules for participants.
• Mentioned as a location where crawlers run paid simulation battles with changing prices and unlockable options.
• Hosts interactive NPCs and location presets like the [[First Level Shopping [[Mall]] (Simulation)]].
• [[Deck]] restrictions and system announcements apply here.
