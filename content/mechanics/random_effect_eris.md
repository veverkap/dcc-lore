# Random Effect: Eris
System mechanic tied to [[Eris]]: while in [[Eris]]'s presence a changing effect is applied each time. In this chapter the spinner chose between "Dick will fall off!" and "Level-15 Pied Piper", ultimately making the Harpocrates benefit permanent. This mechanic is explicitly flagged as variable each encounter.
