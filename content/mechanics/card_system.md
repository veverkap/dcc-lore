# Card System
The new floor-wide mechanic introduced via [[Cascadia]]’s system announcement. Defines decks, card types (Totems, Utility, Snare, Mystic, Special), deck activation rules, timeframe and summon mechanics for totems, discard and draw rates, the effects of practice arenas, and penalties for consumable card use. This announcement governs how squad leaders engage in deck combat and how practice/test arenas operate.
