# Warning: You have exited the current playing field without a registered pass. If you do not immediately return to the playing area, you will be considered to have left the game. Please see <Error>.
An explicit system announcement shown on [[Louis Santiago]]'s HUD when he is detected outside the registered playing area. Functions as a Dungeon/System rule warning about leaving the game boundary.
