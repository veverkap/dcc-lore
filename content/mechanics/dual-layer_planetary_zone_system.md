# Dual-layer planetary zone system
System mechanic described by [[Mexx-6000]]: a main zone from the planet core to sea-level and a secondary zone five kilometers above the surface. It alters interface access and traditionally supports an administrator bubble feature (which Borant elected not to implement in this season).
