# dual-layer_planetary_zone_system

• The dual-layer planetary zone system is a mechanic described by [[Mexx-6000]], consisting of a main zone from the planet's core to [[sea]]-level and a secondary zone five kilometers above the surface.
• This mechanic affects interface access, system AI purview, and expected security features, such as administrator bubbles, in areas like the submerged production [[trailer]].
• The main zone extends from the planet's core to [[sea]]-level, while the secondary zone extends five kilometers above the surface.
• This design affects interface availability and whether an administrator bubble is applied to rentals like the [[Deluxe Rental Trailer]].
• The crawl uses two zoning layers: a main zone (core to [[sea]]-level) and a secondary zone (five kilometers above surface), which dictates what interface features, inventory access, and administrative bubbles are active in locations like the [[Deluxe Rental Trailer]].
• The design decisions of [[borant corporation]] are attributed to this mechanic.
