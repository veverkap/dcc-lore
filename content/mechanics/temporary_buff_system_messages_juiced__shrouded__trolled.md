# [[Temporary Buff System Messages (Juiced / Shrouded / Trolled)]]
In-game system announcements that appear as ephemeral status messages: "You've been Juiced!" (+10% Strength), "You've been Shrouded!" (+10% damage reduction), and "You've been Trolled!" (+25% accelerated healing). Triggered by in-game effects (e.g., [[Imani]]'s ethereal hug).
