# [[Bonding System Announcement]]
System messages that appeared when [[dungeon crawler carl]] bonded with the [[Tummy Acher]]: notifications include "Congratulations. You have bonded with Tummy Acher, level-one", activation of a "Bonded Pets" tab, prompts to name the pet, and confirmation messages such as "Your pet has been named Sir Rendlegore!" These are explicit System Announcement mechanics affecting the interface and pet management.
