# Borant Daily Update
System announcement/patch-note broadcast delivered by [[borant corporation]] within the dungeon. Provides patch notes (e.g., language support, mob removals like [[Blender Fiend]], debuff fixes like Feral Rabies), gameplay guidance, and meta-information about the recap show.
