# Waste Disposal System
An explicit dungeon rule/mechanic: each floor has a system that consumes corpses and spawns janitor mobs (e.g., grubs). It causes mobs to be generated near fresh corpses and drives ecosystem-level spawning behavior described by [[Mordecai]].
