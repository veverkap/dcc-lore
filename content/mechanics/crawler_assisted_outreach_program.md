# crawler_assisted_outreach_program

• A Borant-administered program that automatically enrolls notably popular crawlers in coordinated PR outreach.
• Enrollment assigns a corporate PR agent (e.g., [[Zev]]) who filters interview and appearance requests and schedules [[crawler]] media obligations across floors.
