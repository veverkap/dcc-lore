# Deceased Crawler Message Warning
System announcement type that prefixes messages from dead players/NPCs (e.g., "Warning: This message is from a deceased crawler.") Used in the comms feed to broadcast last warnings such as [[Donita Grace]]'s alert about [[Station 24]].
