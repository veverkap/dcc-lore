# accept_teleport_request

• Accept [[Teleport]] Request: a system interface prompt on [[dungeon [[crawler]] carl]]'s display, asking whether to accept a [[teleport]] request and showing the map destination, which allowed the [[Summon Ally]] mechanic to complete while [[dungeon [[crawler]] carl]] was incapacitated.
