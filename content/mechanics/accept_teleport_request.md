# [[Accept Teleport Request?]]
System interface prompt shown on [[dungeon crawler carl]]’s display asking whether to accept a teleport request and showing the map destination. Central mechanic that allowed the [[Summon Ally]] to complete while [[dungeon crawler carl]] was incapacitated.
