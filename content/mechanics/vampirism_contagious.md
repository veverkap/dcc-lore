# [[Vampirism (contagious)]]
A dungeon rule/mechanic referenced by [[dungeon crawler carl]]: vampirism can spread via infection, turning creatures (and potentially players) into infected, blood-hungry forms. The party takes precautions (e.g., keeping [[Mongo]] away) because of this contagious mechanic.
