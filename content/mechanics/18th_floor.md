# 18th_floor

• The 18th floor is the final floor and the only valid exit point to win the game if [[Scolopendra]] is killed.
• The system enforces a hard-coded rule that crawlers must exit through the final door on the 18th floor to win.
• The 18th floor is named as the required exit point to legitimately win [[Dungeon [[Crawler]] World: Earth]].
• Killing [[Scolopendra]] does not end the game – players must still reach the final door on the 18th floor.
• The 18th floor is an upper floor referenced as having its door opened as part of the post-battle announcements, with escape to this floor noted as difficult.
