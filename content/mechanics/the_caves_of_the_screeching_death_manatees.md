# the_caves_of_the_screeching_death_manatees

• The Caves of the Screeching Death Manatees is a location and a named environment for a race.
• The environment is a cave system populated by massive, hostile manatee creatures.
• The nav device displayed this as the current environment for [[Heat]] number one of seven.
• The Navitron 1000 lists the environment and central hazard for the race.
