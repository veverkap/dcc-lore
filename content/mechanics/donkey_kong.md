# [[Donkey Kong]]
Explicit defensive dungeon rule/trap inside the [[Nest Tower]]: when activated the stairs disappear, convert into a ramp, and rolling barrels (various effects) descend to impede intruders. Described as a costly, last-ditch defense designed to make the path to the main room hazardous.
