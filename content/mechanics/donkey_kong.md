# donkey_kong

• Donkey Kong is a mechanic.
• The [[Donkey Kong]] is an explicit defensive [[dungeon]] rule/trap inside the [[Nest Tower]].
• When activated, the [[stairs]] disappear, convert into a [[ramp]], and rolling barrels with various effects descend to impede intruders.
• This defense is described as a costly, last-ditch defense designed to make the path to the main room hazardous.
