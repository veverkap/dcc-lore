# ascendency

• [[celestial ascendency]]: off-world system/season zone, competitive [[arena]], and production domain for the season
• [[twelfth floor]]: part of the Ascendency floors
• Ascendency: [[dungeon]]/ system event that empowers the local AI and triggers actions by entities like [[Rectrix]]
• Court of the Ascendency: activates a moment, NPCs are [[untouchable]] until the [[celestial ascendency]] starts
• [[Eris]] warns that if "those guys downstairs" win the [[celestial ascendency]], it's catastrophic
• [[Ysalte]] will return to the [[celestial ascendency]] unless interrupted, the place contested for the Ascendent throne
