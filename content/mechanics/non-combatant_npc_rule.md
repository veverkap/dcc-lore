# Non-Combatant NPC Rule
An explicit dungeon rule set describing expected NPC behavior: "Stay put. Hide. You are not a guard. You are not to interfere with conflicts." Violations can result in punishments such as added time on an [[Indentureship Contract]], reassignment to combat roles, or undead reassignment.
