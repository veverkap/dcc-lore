# Upgrade Engineer (System Message)
A system announcement that appears when an NPC in a pouch is identified: "You have discovered an Upgrade Engineer! At least one engineer will appear each race. Engineers can be added to your garage." Signals the presence of an NPC engineer (one such engineer is trapped in the boss pouch) and provides game-rule information about recruitment.
