# Starting Block Shield
A race mechanic announced by [[Dr. Metcalf]]: each team's starting block produces an invulnerability shield that protects a vehicle for the first ninety seconds of the race without affecting controls. This system announcement alters opening tactics for the heat.

# Starting block shield
A new race rule announced by [[Dr. Metcalf]]: each team will be contained in a starting block shield that grants vehicle invulnerability for the first ninety seconds of the race while not affecting controls. Activates automatically at race start and interacts with other defensive effects (e.g., the general "invulnerability shield" on vehicles).
