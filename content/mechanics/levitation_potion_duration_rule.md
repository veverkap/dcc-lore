# Levitation Potion Duration Rule
Explicit dungeon mechanic described in text: a [[levitate]] allows the drinker to rise for a duration equal to the drinker’s intelligence × 2 seconds. The chapter notes uncertainty about maximum height or behavior if the potion expires before descent.
