# Card-battle key-transfer rule
An explicit dungeon rule discussed in the chapter: for [[Princess Donut]] to drop a key to another, a card battle must be initiated and a [[flee card]] used — the system then randomly determines which key is lost, making key transfers mechanically constrained.
