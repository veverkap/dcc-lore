# eighth_level

• The Eighth Level is a location in the World [[Dungeon]] that uses the T’Ghee card combat system.
• The level is described as multiple mountains connected by wires and gondolas, and is the setting for [[Dante]] and [[justice lights team]]'s reassignment.
• The Eighth Level is currently the floor being traversed by the squad, featuring a card-based combat system using [[T’Ghee cards]].
