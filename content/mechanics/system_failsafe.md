# System Failsafe
An explicit orbital contingency device built into the [[Monitor Station (Venus Orbit)]] that, if manually activated, would trigger a catastrophic reaction at the system's star. Mentioned as the mechanism [[princess formidable of the skull empire]] plans to use to annihilate the system.
