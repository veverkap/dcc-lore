# third-party_upgrades

• A new interface tab is created when [[dungeon [[crawler]] carl]] ingests the [[Valtay Corporation Neural Enhancer #544. Variant 32.c]]; it lists communication-based third-party [[upgrades]] and is governed by a warning that such [[upgrades]] are disabled inside the [[dungeon]].
• The interface tab includes a system warning that communication-based [[upgrades]] are disabled inside the [[dungeon]] and that attempts to circumvent security will cause disqualification.
