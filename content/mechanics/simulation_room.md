# simulation_room

• Controlled combat rooms used for practicing [[deck]] usage.
• Damage can occur in simulations, but they prevent some lethal interactions.
• Environment damage is still possible.
• Squads can test decks safely in a controlled environment.
• Carl wants to use a simulation room before deploying a [[deck]] in real combat.
