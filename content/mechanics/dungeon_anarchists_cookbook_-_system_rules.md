# dungeon_anarchists_cookbook_-_system_rules

• The [[The [[Dungeon]] Anarchist’’s Cookbook]] auto-generates after set conditions.
• The book transfers between crawlers after death or retirement.
• The book remains invisible to showrunners but visible to the System AI.
• The book erases its hidden content if revealed to others or if organizers suspect it.
• The book integrates one extra [[scratchpad]] page into the next edition.
