# Dungeon Anarchist’s Cookbook - System Rules
Explicit system behavior for the [[The Dungeon Anarchist’s Cookbook]] described in-chapter: the book auto-generates after set conditions, transfers between crawlers after death or retirement, remains invisible to showrunners but visible to the System AI, erases its hidden content if revealed to others or if organizers suspect it, and integrates one extra [[scratchpad]] page into the next edition.
