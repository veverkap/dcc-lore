# [[Two-part teleport trap rule]]
Explicit constraint discussed by [[Mordecai]]: two-part teleport traps require both anchor and trigger halves to be set by the same user (preventing easy cross-player teleport linking); a core rule that shapes [[dungeon crawler carl]]’s automaton workaround.
