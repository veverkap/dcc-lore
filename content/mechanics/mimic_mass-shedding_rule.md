# Mimic mass-shedding rule
Dungeon rule for large mimics: if more than ~50% of the mimic’s mass is removed from the main body at once, the main body can no longer heal or transform (becomes vulnerable). Separated pieces will grow legs and attack; those pieces only die when the main mimic dies.
