# Ghoul Generator Spawn Rule
Explicit dungeon mechanic described in-text: "For every non-undead mob that dies within this floor, one of the soul crystal-powered ghoul generators will birth a single Blister Ghoul." This rule governs continuous undead spawns from [[Ghoul Generator]] devices.
