# [[System Announcement: Murderer Level-Up]]
An explicit in-game System Announcement that triggers upon killing [[Hunter Iota]]: "Congratulations, Murderer. You have leveled up the Ring of Divine Suffering. It now gives four stat points for every kill." This functions as an active mechanic/announcement within the crawl's ruleset.
