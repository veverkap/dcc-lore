# death_challenge

• [[Death Challenge!]]: an in-world system announcement/televised event overlay that dramatizes and broadcasts [[dungeon [[crawler]] carl]]'s imminent death, presented with graphics, music, and announcer text.
• A pop-up gambling event where viewers bet on multiple possible outcomes with variable odds, referencing named entities like [[Grull]] and [[Mimic]] and subject to appeals (e.g., by [[borant corporation]]).
• The system AI initially set [[dungeon [[crawler]] carl]]'s survival at 50:1 in one instance.
• Outcomes can reference named entities like [[Grull]] and [[Mimic]].
• The event triggers on-screen portraits, commentary, and rules notifications during the chapter's boss event.
• The system broadcast/announcement frames the encounter as a live televised death match.
• The event is distinct from a boss battle and is subject to appeals like the one filed by [[borant corporation]].
• The system broadcast/announcement frames [[dungeon [[crawler]] carl]]'s encounter as a televised match between [[mimic]] and [[Grull]] with commentary, portraits, and strobing effects.
• Classified as an active System Announcement within the chapter.
