# Veriluxx New Toys Showcase
A televised/staged commercial program and studio space where [[dungeon crawler carl]] and [[Robot Donut]] appear to promote toys. Filmed inside a rented production trailer (an underwater security trailer in this chapter) and run by hosts of the [[forsoothed soothers]] type.
