# track_randomization

• A system announcement rule delivered by [[Zev]] states that each track has four heats, the [[Pit Stop]] combines four tracks, and each [[heat]] rolls to determine which path it continues on.
• When the leading team in a [[heat]] times out, other teams are reassigned according to a random draw.
