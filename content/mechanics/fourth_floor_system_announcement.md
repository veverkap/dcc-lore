# Fourth Floor System Announcement
The daily system message that opens the chapter: "Hello, Crawlers. Welcome to the fourth floor!" It introduces the [[the tangle]], states the floor-specific rule about stairwell timing, announces patron bidding, and activates hunting/bounty mechanics and the populated leaderboard.
