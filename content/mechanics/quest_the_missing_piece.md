# [[Quest: The Missing Piece]]
System announcement for a new hybrid world quest tied to the current event. Part one ("The Big O") is restricted to the [[Cuba region]]; all crawlers in the region are hosts. The quest ties into the [[Amayon]]/[[Ysalte]] battle and has a ten-minute timer for resolution.
