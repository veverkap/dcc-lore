# Admin Notice (Sponsorship Notification)
A system announcement mechanic that informs the player-crawler ([[dungeon crawler carl]]) of sponsorship events: here it notifies of receiving the third sponsor ([[apothecary]]) and triggers viewer-facing advertising and UI changes (Sponsorship Tab).
