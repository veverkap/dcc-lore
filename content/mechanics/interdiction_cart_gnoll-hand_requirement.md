# [[Interdiction cart gnoll-hand requirement]]
The explicit activation rule for [[Interdiction Rapid-Response Railway Repair Cart]] consoles: the carts only start when two gnoll hands (on spaced sensor plates) are placed, and an additional rule indicates a specific left-hand requirement on one plate.
