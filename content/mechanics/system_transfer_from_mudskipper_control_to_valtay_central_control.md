# System transfer from mudskipper control to Valtay central control
An explicit system announcement/hand-off reported by [[Lexis]]: the game's control is being transferred from [[kua-tin]] to [[Valtay]] central control. This mechanic triggers temporary windows with no sniffers, a planned top-player transfer to the high-elf event, and broad operational changes.
