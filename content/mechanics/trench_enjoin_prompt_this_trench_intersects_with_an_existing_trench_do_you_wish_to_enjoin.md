# Trench Enjoin Prompt: This Trench intersects with an existing trench. Do you wish to enjoin?
An in-interface decision prompt presented when using [[Build Trench (Scroll)]], allowing players to merge a newly created channel with an existing trench (accepting causes immediate terrain changes).
