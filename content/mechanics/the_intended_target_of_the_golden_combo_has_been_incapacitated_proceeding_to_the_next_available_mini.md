# the_intended_target_of_the_golden_combo_has_been_incapacitated_proceeding_to_the_next_available_mini

• The intended [[target]] of the Golden Combo has been incapacitated.
• Proceeding to the next available minion [[target]].
• System message produced when [[Golden Combo]] tries to combine minions but the chosen [[target]] is incapacitated; precedes an automatic [[target]] reassignment in play.
• System message produced when a combo card [[Golden Combo]] attempts to combine minions but the original [[target]] is unavailable, causing the combo to [[target]] an unintended entity.
