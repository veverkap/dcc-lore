# Earth Memory Loot Dissipation Rule
Explicit dungeon rule from the announcement: any tangible loot taken from the floor’s Earth memory will turn to dust upon level collapse and cannot be carried to subsequent floors. This governs looting strategy and limits long-term armament from local militaries or caches.
