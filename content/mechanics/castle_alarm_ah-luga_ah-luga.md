# Castle Alarm 'ah-luga, ah-luga'
A system announcement pattern used by [[Fort Freedom]]'s alarm system. The "ah-luga, ah-luga" pattern is an explicit system message meaning "attackers at the main gate; all defenders converge at the front," and drives the castle's defensive response when triggered.
