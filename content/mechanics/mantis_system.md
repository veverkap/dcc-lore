# mantis_system

• The Mantis system is a stellar manufacturing location where Macro AIs are built and programmed before being installed into Primal Engines.
• The system has exploded, tied to inter-species animosity between mantids and the tenodera, including the destruction of Hive Re-Population Center 51.
• The system was annihilated by a rogue AI, illustrating the scale of the crisis described by [[Prime Minister Victory]].
• The system houses a manufacturing facility used to build Macro AIs that run portions of the crawl.
