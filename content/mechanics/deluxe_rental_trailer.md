# Deluxe Rental Trailer
The underwater, off-world celebrity trailer rented from [[Senegal Production Systems, Unlimited]] where Carl and [[Donut]] record. Contains amenities (makeup table, refrigerating shelves), controlled by [[Mexx-6000]], and resides below sea level (inside the [[Dual-layer planetary zone system]]'s main zone).

# Deluxe Rental Trailer
Undersea production trailer owned by [[Senegal Production Systems]] used as a studio set in this chapter. Features include a large picture window showing the ocean floor, a studio booth, refrigerating shelves, and an AI attendant ([[Mexx-6000]]). Functions as a secure rental that nevertheless permits full UI access due to corporate zoning choices.
