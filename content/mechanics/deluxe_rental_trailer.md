# deluxe_rental_trailer

• The Deluxe Rental [[Trailer]] is an underwater, off-world celebrity [[trailer]] rented from [[Senegal Production Systems, Unlimited]].
• It contains amenities such as a makeup table and refrigerating shelves, controlled by [[Mexx-6000]].
• The [[trailer]] resides below [[sea]] level, inside the [[Dual-layer planetary zone system]]'s main zone.
• It is owned by [[Senegal Production Systems]] and used as a [[studio]] set.
• Features include a large picture window showing the ocean floor, a [[studio]] booth, refrigerating shelves, and an AI attendant [[Mexx-6000]].
• The [[trailer]] functions as a secure rental with full UI access due to corporate zoning choices.
