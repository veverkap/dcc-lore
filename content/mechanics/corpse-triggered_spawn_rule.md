# corpse-triggered_spawn_rule

• When a corpse is created in an area, the [[Waste Disposal System]] can spawn between one and fifteen janitor mobs (grubs) to process it.
• If janitor mobs are absent, spawning increases.
• Destroying corpses prevents leveling but does not stop spawn generation.
