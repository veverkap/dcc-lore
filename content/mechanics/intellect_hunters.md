# intellect_hunters

• Alien/parasite-type entities that take over corpses, leading to rotting bodies.
• Can be used to explain how off-world intelligences can "wear" bodies, analogous to how aliens inhabit gods.
• Part of a set with [[the Scree]] and [[Valtay]].
• Contrasted with other parasite types like [[Valtay]] and the [[Infiltrator]].
• Used by [[Mordecai]] to explain parasite variants.
