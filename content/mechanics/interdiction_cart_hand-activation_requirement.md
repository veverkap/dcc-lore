# interdiction_cart_hand-activation_requirement

• The Interdiction Cart requires two [[gnoll]] hands placed on separated hand-shaped key consoles to start.
• The system enforces spacing, preventing one operator from activating both consoles simultaneously.
• In some cases, the system also enforces handedness, requiring the use of a specific hand (e.g., the left hand).
