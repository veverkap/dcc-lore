# Locked Door Notification
A system message observed when [[dungeon crawler carl]] touched the magistrate's chamber door: "This door is locked. Magically locked. It’s almost like they don’t want you going in there." Represents an in-world active system announcement restricting access to [[Magistrate FeatherFall]]'s office.
