# Class Selection
The in-dungeon mechanical choice process discussed by [[Odette]] and [[dungeon crawler carl]]—a core system interaction that determines available paths/skills (e.g., pathfinder or mapping abilities) and can include rare, charisma-gated options that may have moral consequences.
