# Eighth Floor System Announcement
The active system message delivered on entry that defines the floor rules: phase timers (e.g., "Time to Level Collapse," "Time until Phase Two"), phase structure, squad formation and limits, region exploration radii, tangible-vs-ghost rules for Earth memory objects, flag/T’Ghee mechanics (summoning, limits, trade/dismiss rules), and item collapse behavior. This mechanic governs player behavior on [[Eighth Floor: The Ghosts of Earth]].
