# main_drainage_tunnel

• The Main Drainage [[Tunnel]] is a sewer/pipe system that runs from the [[necropolis]] to the ocean.
• It contains a wheel/panel that, if opened, will flush water and can be used to collapse the [[sandcastle]] in the "easy" plan.
