# gate_cancels_if_the_winding_box_moves_more_than_five_feet

• [[Gate]] cancels if the winding box moves more than five feet.
• This is a physical stability rule that dictates defensive positioning.
• The [[gate]] activation will be canceled if the box shifts more than five feet after being set and counting down.
• This is an explicit mechanical constraint keyed to the [[Winding Box]] placement.
