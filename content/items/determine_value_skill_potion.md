# determine_value_skill_potion

• A skill potion reward from a [[Gold]] Looter box that allows Carl to see item rarities (and previously value-related information), changing how he inspects inventory like the [[kimaris figure]].
• A consumable that grants the Determine Value skill, allowing [[dungeon crawler carl]] to see item rarity (but not exact monetary value); received from a [[Gold]] Looter box during the day.
• A skill potion prize given from a [[Gold]] Looter box that grants the [[Determine Value]] skill (used to reveal item rarities/values); one such potion was obtained by [[dungeon crawler carl]].
• A skill potion found in a [[Gold Looter Box]] that increased Carl's Determine Value skill to level two when consumed.
• A consumable potion that added additional inventory sort options and a new History tab for [[dungeon crawler carl]]'s inventory. Does not directly reveal monetary value of individual items.
