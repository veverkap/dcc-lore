# hole

Here is the consolidated markdown list:

* Creates a temporary hole on a chosen surface; level-dependent thickness and utility.
* Useful for creative traversal and bypassing obstacles.
* Can be used to trip or impede enemies during combat.
* Can be used to bypass doors and create openings during combat.
* Can be used to [[teleport]] or shift occupants between rooms.
* Can be used to create an extradimensional opening leading outside.
* Can be used to create an opening in the bottom of the Vahana basket.
* Can be used to remove portions of doors or walls temporarily.
* Can be used to create an instant aperture in flooring or carpet.
* Can be used to drop the team from one apartment to another.
* Can be used to create a void/drop allowing the racing [[truck]] to descend between floors.
* Can be used to open passages between apartments and floors.
* Can be used to create a [[portal]]/teleportation spell to open passages between apartments and floors.
