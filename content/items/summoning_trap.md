# Summoning Trap
A described trap item found and disarmed by [[dungeon crawler carl]]; labeled a "Recycled Trap" in its writeup. Effect: once triggered, it summons two local guards/minions (programmable at a [[Sapper’s Table]]). One-use, short delay, and programmable targeting make it a tactical deployable if the user controls minions or a town.

# [[Summoning Trap]]
A recycled trap item found in multiple copies. Explicit description in-chapter: when triggered it summons two town guards or minions from the current floor (programmable at a [[Sapper's Table]]), has a two-second delay, single use, and can misfire if no minions/town control exist. Collected as loot for possible tactical use.
