# Benefactor Box
A high-tier loot container that patrons can send; contains rare items and goods (potentially from a patron's home world). Distinguished from ordinary Adventurer boxes by rarity and contents. Tiers run from Bronze → Silver → Gold → Platinum → Legendary → Celestial, with Benefactor Boxes being particularly coveted.
