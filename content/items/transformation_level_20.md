# Transformation (Level 20)
A spell-like system effect applied by the dungeon as part of the attack. [[Transformation (Level 20)]] changed forms (e.g., into a quadruped), altered equipment slots and stats, and added new UI actions; it is presented in-game as a levelled transformation effect.
