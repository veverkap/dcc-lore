# entourage

• A bard spell that creates multiple illusionary versions of each party member; one of the support songs [[Donut]] can cast if she sings steadily.
• Creates illusionary copies of each party member, including a single transparent Carl.
• Can be used for deception, such as creating stationary illusory Donuts during a pub encounter.
• Can be combined with other spells, like [[invisibility]] and [[Hole]], for a trick.
• Donut is attempting to cast the spell to create illusionary duplicates, but currently only produces a single transparent illusionary [[Dungeon Crawler Carl]] when attempted.
