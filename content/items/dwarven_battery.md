# dwarven_battery

* Brick-sized rechargeable batteries used to power carts; common across crawls and refillable by mana [[potions]].
* Found in carts at low charge and replenishable via the [[Dwarven [[battery]] fabricator]] using mana [[potions]].
* Portable power source, possibly used to provide electricity to test or energize the castle doorway.
* Damaged power cells salvaged from destroyed [[Dwarven Industrial [[Light]]-Duty Automaton]]s, used for crafting and building defenses.
* Used by [[dungeon crawler carl]] to run an iPod and Bluetooth speaker in the [[saferoom]], enabling Earth electronics.
* Common rechargeable power cell used to run carts; the party salvages one and has many rechargeable units produced via a [[Dwarven [[battery]] fabricator]] using mana [[potions]].
