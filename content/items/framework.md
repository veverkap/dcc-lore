# Framework
The huge, reusable physical structure described as the dungeon's "framework" — a third-to-last installed physical object that contains stored mobs, reusable locations, and indentured workers; moved planet-to-planet and fed season plans before the [[Macro AI]] and [[Primal Engine]] are installed.
