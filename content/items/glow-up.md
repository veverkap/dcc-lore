# Glow-Up
A mythic consumable special-effect card (not a standard card type). Can be cast on any active card/totem (ally or enemy) to permanently set that card’s current altered state (e.g., increased summon time). Single-use; strategic, potentially turning a strong totem into an effectively immortal one.
