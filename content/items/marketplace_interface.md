# marketplace_interface

• A purchased upgrade that provides a virtual trading store (buy/sell/bid auctions).
• Account ownership (credit bonus) affects prices (e.g., [[Donut]]'s Charisma bonus).
• Advised caution with heirlooms like [[The Dungeon Anarchist’s Cookbook]].
• A purchasable upgrade acting as a virtual general-store/commercial UI that allows buying, selling, and eventual auctions (sixth-floor focus).
• Linked to account ownership and Charisma bonuses (e.g., [[Donut]]'s account).
