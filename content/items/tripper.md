# tripper

• Automatically triggers passage, motion, heat, and weight-based traps in a radius calculated from caster Intelligence.
• Does not disarm traps, has an item-based cooldown, and is item-locked.
• Can be used to trigger nearby traps, including Spirit Box traps, to manipulate spawn and trap behavior.
• Can be used to clear areas and set off traps, including [[landmine]] explosions.
• Can be used to trigger multiple traps simultaneously, causing battlefield chaos.
• Can be used to trigger traps in advance of [[automaton]] deployments, and is used in coordinated raid timing with [[Ping]] and [[Dread]].
• Can be used to eliminate enemies, such as Zabit, when they try to vanish with an invisibility potion.
• Can be used to trigger traps and coordinate the timing of an assault before detonating [[automaton]] spiders.
