# final_blow

• A high-tier skill owned by [[Mordecai]] that can target individuals and transfer a received spell effect to the targeted object.
• Can mark an individual target so that spells affecting the marked person also affect the targeted object.
• Used by [[Mordecai]] to try to link the puzzle to himself.
• Presented as one of his core abilities and a catalyst for the crisis.
• Can be used to detect hidden mobs.
• Can be used to transfer a received spell effect to the targeted object (in this case, the [[Puzzle Disk]]).
