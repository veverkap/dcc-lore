# protective_shell

Here is the consolidated list of unique factual points about the Protective Shell:

• Creates a static, non-moving sphere that blocks physical presence and attacks for a short duration.
• Does not protect against magic or non-corporeal entities.
• Can be cast periodically to provide protective effects.
• Has a cooldown period, which can be affected by the caster's intelligence.
• Can be used to create a temporary dome protecting allies.
• Can be used to block mental/parasitic intrusion from Heather's worms.
• Can be used to mitigate throat/holding damage during a grapple.
• Can be used to create a massive [[shield]] that repels mobs and clears space.
• Can be used to [[launch]] enemies and scatter them.
• Can be used to create a semi-circular, impenetrable barrier.
• Can be used to absorb impacts and protect the caster.
• Has a limited duration before expiring.
• Can be used to create a moving protective sphere.
• Can be used to [[launch]] enemies and create a cratered safe zone.
• Can be used to [[shield]] the caster and allies from a large area blast.
• Can be used to knock back or displace nearby mobs when activated.
• Has a daily use limit.
• Can be upgraded in the combined training room.
• Is associated with an equipment piece (the boxer shorts) that can be trained/enhanced.
