# Purple Charge Pillow
A second charging pillow Donut receives (platinum benefactor). Functions like the [[Accompanying Charge Pillow]] but differs: it will drain any magical item but can only transfer to a like item (e.g., ring-to-ring); described as more universal but with compatibility restrictions.

# Purple Charge Pillow
A second charge pillow received by [[Donut]] (nearly identical to the red pillow but purple). It drains magical items in ten hours and only transfers drained buffs to compatible item types (e.g., ring-to-ring compatibility warning). Functions as a more "universal" or type-restricted charger compared to the red pillow.
