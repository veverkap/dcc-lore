# silver_earth_box

• [[Silver Earth Box]] is a floor-class incentive awarded for selecting an Earth Class and serves as a named item reward on class selection.
• A reward item tied to Earth-class choices, awarded when choosing an Earth class (mentioned for [[Bomb]] Squad Tech, [[Prizefighter]], Compensated Anarchist).
• A tiered loot box received by both [[dungeon crawler carl]] and [[Donut]] containing Earth-themed items and an [[Earth Hobby Potion]].
