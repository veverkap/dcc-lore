# automaton_table

• Level-five crafting station used to produce [[automaton]] constructs like spiders, upgradeable with parts from boxes like the [[Platinum Tserendolgor box]].
• Crafting station used by [[Mordecai]] to analyze [[potions]] and construct [[automaton]] parts, upgradeable toward building a [[Fabricator]].
• Crafting station in [[dungeon crawler carl]]’s possession used by [[Katia]] to build devices (e.g., for [[Tran]]), part of the group’s engineering and vehicle plans.
• Level-five crafting bench used to build automata and related constructs, acquired by Carl along with an instruction manual/recipe book and used to create items like [[Spider Stalkers]].
• A tangible, purchasable/awarded item found in the studio, added to [[dungeon crawler carl]]’s inventory after realizing it’s physically present in the empty studio, and later interacts with the book [[Dr. Ratchet’’s Guide to Building Automatons for Fun and Profit]].
