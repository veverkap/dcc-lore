# skedaddle

• A specific song-sheet (sheet music) available for bards (ten-hand cost) that grants a double-jump escape ability when used correctly (requires singing in [[key]]).
• Carried by [[Donut]] for emergency retreats.
• Named mobility/escape ability cited by [[Donut]] as not functioning for the required distance in the current plan.
• An escape spell/card in [[Donut]]'s deck that risks dumping the user into [[Sheol]] when used in the current situation.
• An escape spell/card in [[Donut]]'s hand that would forcibly remove characters but with dangerous landing consequences in the current environment.
