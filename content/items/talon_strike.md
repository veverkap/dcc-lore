# talon_strike

Here is the consolidated list of unique factual points about Talon Strike:

• A melee skill granted by a gem on the Enchanted Necklace of the Haute Bourgeoisie.
• Temporarily turns the side of the foot into a slashing weapon.
• Scales with skill level.
• Has a chance to cast the instakill spell Eviscerate (2% per kick).
• Reaches permanent activation at skill level 15.
• Can be used to finish off enemies quickly.
• Can be used to stun and finish off enemies.
• Can be used to deal damage and contribute to melee defense.
• Can be used to kick and strike enemies.
• Can be used to deliver [[precision]] strikes to the head.
• Can be used to attempt a decisive stomp.
• Can be used to kick and strike non-corporeal foes without suffering freeze effects from contact.
• Can be used to break and destroy enemies.
• Can be used to finish off multiple weakened enemies in a single action.
