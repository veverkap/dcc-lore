# hunter-killer_box

• A prize box type that Carl owns 34 of, containing incremental [[gold]] payouts and severed appendages (trophy hands/claws) from named mobs, labeled as [[Hunting Trophy]]s, and can be transferred but revert to generic appendages if sold.
• Stacked prize boxes Carl opened (34 total), containing incremental [[gold]] payouts and severed trophy hands/claws from sponsors (e.g., [[Xindy]], [[Chin’dúa]]), totaling 595,000 [[gold]].
