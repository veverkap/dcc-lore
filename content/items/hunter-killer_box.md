# Hunter-Killer Box
A prize box type that Carl owns 34 of. Contents in this chapter include incremental gold payouts and severed appendages (trophy hands/claws) from named mobs. Items are labeled as [[Hunting Trophy]]s and can be transferred but revert to generic appendages if sold.
