# lightning_lou

• The name "Lightning Lou" is on a sign over [[an]] elderly memory-ghost bloodhound found sleeping in a closed gas station.
• The memory ghost [[dog]], Lightning Lou, haunts the lonely Gas Station, sleeping and snoring while [[dungeon crawler carl]] visits.
• [[dungeon crawler carl]] attempts to pet the [[dog]] but his hand passes through the memory ghost.
• The memory of Lightning Lou is remembered by [[dungeon crawler carl]] as part of a memory that illustrates the close proximity to mental breakdown in the dungeon setting.
